# Sheetcord

**디스코드 대화를 엑셀처럼.** 디스코드 웹에 적용하는 크롬·엣지용 Manifest V3 확장 프로그램입니다.

초록색 리본, 수식 입력줄로 꾸민 실제 채팅 입력기, 메시지 셀 격자, 서버 시트 탭, 왼쪽 채널·DM 목록을 제공합니다. 프로필 사진·이모지는 기본 숨김이며 리본과 확장 설정창에서 켜거나 끌 수 있습니다. 이미지·GIF·스티커는 기본으로 접혀 있으며 메시지에서 개별로 펼칩니다.

현재 **0.4.0**입니다. 서버·하위 채널 탐색, 미디어 접기, 스레드·포럼·임베드 서식을 묶고 포럼의 자동 목록 보기를 추가했습니다. 기본 대화는 시간·작성자·본문 열로 배치합니다. 긴 글·여러 줄 내용과 펼친 미디어는 옆 열까지 사용하며, 입장·부스트 알림은 안내 기록으로, 임베드는 제목·설명·항목/값의 여러 행과 열로 표시합니다. 메시지 하나를 한 셀에 가두지 않습니다. 작은 창에도 리본과 셀 격자를 유지합니다.

실제 Chrome에서 서버·채널·그룹 DM 이동, 한글·줄바꿈·답장·텍스트 첨부·스티커 전송, 표시 전환과 원래 화면 복원을 확인했습니다. 자동 테스트는 116개입니다. **Edge의 실제 계정 점검과 Windows IME 조합 중 Enter의 수동 점검은 남아 있습니다.** 검증 범위는 [VALIDATION.md](VALIDATION.md)를 확인하세요.

## 설치

1. 제공된 `sheetcord-0.4.0.zip`을 새 폴더에 압축 해제합니다. 소스 폴더를 받았다면 빌드 결과인 `dist`를 사용합니다.
2. 크롬에서는 주소창에 `chrome://extensions`, 엣지에서는 `edge://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. `manifest.json`이 바로 들어 있는 압축 해제 폴더 또는 `dist` 폴더를 선택합니다.
5. [디스코드 웹](https://discord.com/channels/@me)을 열고 본인이 로그인합니다. 채팅 페이지를 한 번 새로고침합니다.
6. 확장 아이콘을 고정해 두면 껐다 켜거나 표시 설정을 변경하기 편합니다.

로그인 페이지는 적용 범위가 아닙니다. 로그인 직후 SPA 이동만으로 채팅 화면에 들어온 경우 새로고침이 필요합니다. 확장 업데이트를 다시 로드했을 때도 열려 있던 디스코드 페이지를 새로고침하세요.

**기존 설치 업데이트:** 등록해 둔 확장 폴더의 파일을 새 ZIP 내용으로 덮어쓴 뒤, 확장 관리 화면에서 Sheetcord의 새로고침 버튼을 누르고 디스코드 페이지도 새로고침하세요.

## 사용법

**브라우저 탭:** Sheetcord가 켜져 있으면 탭 아이콘을 투명하게 표시합니다. 확장 아이콘을 누르고 **브라우저 탭 이름**에 원하는 이름을 입력한 뒤 **저장**을 누르세요. 기본 이름은 `통합 문서1.xlsx`이며, 최대 80자까지 이 브라우저에 저장합니다. 이름을 비우면 원래 제목을 사용합니다. 채널 이동·알림으로 원래 제목이 바뀌어도 지정한 이름을 유지하며, `원래 화면`으로 돌아가면 최신 디스코드 제목·아이콘을 복원합니다. 아이콘 자리 자체나 브라우저가 표시하는 음성·마이크 상태 아이콘을 제거하는 기능은 아닙니다.

**작은 창:** 창이 좁아져도 리본 높이와 버튼 크기는 유지하며, 넘치는 도구와 채널 바로가기는 가로 스크롤로 확인합니다. 리본에는 세로 스크롤이 생기지 않습니다. 채널 바로가기는 두 줄로 표시하고 긴 이름은 툴팁으로 확인할 수 있습니다. 입력줄은 위쪽에 놓이고, 가로 600px 이하에서는 왼쪽 채널 목록을 숨깁니다. 디스코드의 상단 `받은 편지함`·`도움말` 버튼은 Sheetcord 화면에서 숨기며, `원래 화면`으로 돌아가면 복원됩니다.

| 위치 | 동작 |
| --- | --- |
| `파일` 한 번 클릭 | 개인 메시지·서버·폴더 목록을 열고 이름으로 검색. 현재 서버와 읽지 않은 표시 유지 |
| `보기` 한 번 클릭 | 알림 설정·멤버 목록 등 현재 채널의 도구 열기 |
| `삽입` 한 번 클릭 | 현재 서버의 채널·활성 스레드·포스트 또는 DM 목록을 검색하고 이동. 왼쪽 창을 접은 상태에서도 사용 가능 |
| 아래 시트 탭 | 개인 메시지·서버 이동. 긴 목록은 화살표나 가로 스크롤로 이동 |
| 왼쪽 작업 창 | 현재 서버의 채널 또는 DM 선택 |
| 상단 `C · 입력` / `ƒx` 옆 입력줄 | 실제 디스코드 입력기. Enter 전송, Shift+Enter 줄바꿈 |
| `프로필 사진 표시` | 메시지·왼쪽 목록의 프로필 사진 켜기·끄기 |
| 메시지의 `이미지 펼치기`·`스티커 펼치기` | 해당 항목만 펼치기·접기. 펼친 이미지의 원래 링크·원본 보기 유지 |
| `이미지 모두 접기` | 현재 대화에서 펼친 이미지를 모두 접기 |
| `이모지 표시` | 끄면 `:thumbsup:` 같은 이름 또는 `[이모지 U+…]`로 표시 |
| 리본의 `채널 창` | 왼쪽 창 접기·펼치기 |
| `대화 검색` | 디스코드의 기존 검색 입력란 열기 |
| `원래 화면` | 추가 UI, 스타일, 메시지 처리, DOM 감시를 해제하고 원래 화면 복원 |
| 확장 아이콘 | 화면 재활성화, 표시 설정, 현재 탭에 다시 적용 |

답장·멘션·반응·첨부는 디스코드의 기존 동작을 이용합니다. 텍스트 대체 상태에서도 반응 클릭은 원래 반응 버튼으로 전달합니다. 스포일러는 이미지를 펼친 뒤에도 별도로 공개해야 합니다. `파일`에는 서버 목록, `삽입`에는 채널 목록이 있습니다. 수식 등 나머지 제목은 엑셀 외형을 위한 장식이며 실제 파일 편집 기능은 아닙니다.

상단 목록은 이름을 줄바꿈해 표시하며 긴 목록은 목록 안에서 스크롤합니다. Esc 또는 바깥 클릭으로 닫고 방향키로 항목을 선택할 수 있습니다. 채널 목록은 원래 작업 창을 끝까지 스크롤해 수집한 뒤 원래 위치로 복원합니다. 화면 밖 항목도 상단 바로가기와 검색 목록에 유지하고, 채널 메뉴를 다시 열면 목록을 재확인합니다. 수집 중 원래 목록을 조작하면 중단합니다. 접힌 카테고리를 자동으로 펼치거나 별도 API로 채널을 불러오지는 않습니다.

채널 창을 접거나 작은 창으로 보더라도 `삽입 → 채널 목록`은 유지합니다. 디스코드가 숨겨진 목록을 잠시 비우면 현재 서버에서 확인한 채널 목록을 메모리에서 사용하며, 이 경우 채널 선택은 해당 주소로 페이지를 엽니다. 서버 이동·확장 해제 시 이 임시 목록은 비워집니다. 접힌 스티커는 일반 래퍼나 행에 지정된 고정 높이도 해제해 한 줄로 표시합니다.

**미디어 접기:** 사진·GIF·스티커는 항상 접힌 상태로 시작하며 각 항목을 메시지 한 줄 높이로 표시합니다. 개별 펼치기에는 별도 설정이 필요하지 않습니다. 리본의 `이미지 모두 접기`는 현재 대화에서 펼친 항목을 다시 접습니다. 큰 이모지도 숨김 상태에서는 일반 텍스트 높이로 표시합니다. GIF·스티커 보내기 목록은 이름으로 표시하며, 이모지 선택 목록은 이모지 표시 설정을 따릅니다. 항목 위치·선택·비활성 상태는 디스코드의 원래 동작을 유지합니다. 페이지에 이름 정보가 없는 항목은 `GIF (이름 없음)` 같은 대체 이름을 사용합니다.

숨긴 스티커는 일반 이미지 요소 안에 들어 있어도 스티커 주소·이름표를 확인해 `[스티커: 이름]`으로 표시합니다. 이름 정보가 없는 경우에는 `스티커 숨김`으로 표시하며, 미공개 스포일러 안의 이름은 노출하지 않습니다. 고정된 메시지 버튼도 Sheetcord가 켜진 동안 초록색 계열로 표시합니다.

**스레드 인용:** 흰색 셀 안에 얇은 회색 테두리와 초록색 제목으로 표시합니다. 제목·메시지 수와 최근 내용은 두 줄로 정리하며 긴 내용은 말줄임합니다. 원래 스레드 열기 동작을 유지하고 화면 읽기용 설명은 중복 노출하지 않습니다. 스레드가 달린 긴 본문은 기본 세 줄로 접고 `내용 펼치기`·`내용 접기`로 전환합니다. 원문은 변경하지 않으며 연결선이 셀이나 버튼을 덮지 않도록 처리합니다.

스티커의 펼치기·접기는 정보 창을 열지 않습니다. 펼친 그림을 눌렀을 때만 원래 스티커 정보가 열립니다. 펼친 스티커는 160px 크기를 기준으로 셀 너비에 맞춰 표시하며 메시지 행도 함께 늘어납니다.

## 로컬 개발과 미리보기

Node.js 22.18 이상(24 권장)과 pnpm을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
pnpm package
```

`pnpm dev` 실행 후 표시되는 로컬 주소(기본 `http://127.0.0.1:5173`)로 들어가면 샘플 화면을 체험할 수 있습니다. 샘플 도구에서 메시지 수신, 과거 메시지 로딩, 긴 서버 탭, 화면 구조 변경·복구를 재현할 수 있습니다. **샘플 페이지는 디스코드에 연결하지 않으며 입력한 메시지는 외부로 전송되지 않습니다.**

`pnpm build`는 타입 검사 후 `dist/`를 생성합니다. `pnpm package`는 마지막 빌드를 매니페스트 버전에 맞는 `artifacts/sheetcord-0.4.0.zip`으로 묶습니다. 코드 변경 후에는 반드시 먼저 다시 빌드하세요. 테스트는 브라우저 확장을 설치하지 않고 Happy DOM의 테스트용 DOM에서 실행합니다.

## 구조와 데이터 처리

- `src/adapter.ts`: DOM 탐색, 서버 탭, 채널명, 입력기 탐색. 공개된 DOM 속성을 우선하고 클래스 이름 일부를 보조적으로 사용합니다.
- `src/controller.ts`: 활성화·해제, 화면 변경 감시, 호환성 실패 시 복원, 입력줄 높이 조절.
- `src/shell.ts`, `src/theme.css`: 엑셀 외형과 UI.
- `src/navigation.ts`: 상단 서버·채널 목록, 이름 검색과 키보드 이동.
- `src/channel-scan.ts`: 가상 채널 목록 스크롤 수집과 원래 위치 복원.
- `src/picker.ts`: GIF·스티커·이모지 선택 목록의 이름 표시.
- `src/messages.ts`, `src/avatars.ts`, `src/media.ts`, `src/emoji.ts`: 행·프로필 사진·이미지·이모지 표시층.
- `src/settings.ts`, `src/popup.ts`: 확장 설정과 팝업.
- `src/tab.ts`: 탭 아이콘 숨김, 사용자 지정 제목 및 원래 탭 표시 복원.

외부 API·서버·분석 도구를 사용하지 않습니다. 메시지 전송을 자체 구현하지 않으며, 계정 토큰·쿠키·React 내부 상태를 읽지 않습니다. 콘텐츠 스크립트는 `ISOLATED` 환경에서 실행하며, 선언된 적용 범위는 채팅(`channels/*`), Nitro(`store*`), 상점(`shop*`), 퀘스트(`quest-home*`) 페이지입니다. 로그인 페이지는 포함하지 않습니다. 설정 저장에 필요한 `storage` 권한만 선언합니다.

메시지·작성자·첨부 표시를 위해 현재 페이지 DOM을 읽습니다. 그 정보는 서버로 전송하거나 디스크에 저장하지 않습니다. `chrome.storage.local`에는 `enabled`, `showAvatars`, `showEmoji`, `sidebarCollapsed` 표시 설정과 `tabTitle` 탭 이름만 저장합니다. 이전 버전의 `showImages` 값은 무시하고 다음 설정 저장 시 제거합니다. 샘플 페이지의 표시 설정은 별도의 로컬스토리지 키로 저장합니다.

## 첫 버전의 제한

- Discord는 공개 DOM 호환성 계약을 제공하지 않습니다. 주요 구조를 찾지 못하면 원래 화면으로 복원하고 재시도 안내를 표시합니다. 구조 일부만 바뀌면 시각적 어긋남이 남을 수 있습니다.
- 닫힌 서버 폴더는 폴더 탭으로 표시하며, 누르면 원래 폴더 동작을 실행합니다. 그 안의 서버는 Discord가 DOM에 표시한 순서대로 추가됩니다. DOM에 없는 서버·과거 메시지를 별도로 가져오지 않습니다.
- 서버 이름은 연결된 접근성 이름표, 직접 이름, 아이콘 설명 등을 확인합니다. 확인 가능한 이름이 전혀 없으면 빈 탭 대신 `서버 (ID)`로 표시합니다. 긴 이름은 잘라내지 않고 가로 스크롤로 확인할 수 있습니다.
- 행 번호는 현재 세션에서 처음 표시된 순서에 부여하는 로컬 참조 번호입니다. 과거 메시지를 추가하면 화면의 번호가 연속 오름차순이 아닐 수 있습니다. 원래 메시지 번호나 전체 메시지 수를 의미하지 않습니다.
- 그룹으로 묶인 메시지는 현재 렌더링된 앞 메시지에서 작성자를 이어 표시합니다. 확인할 수 없는 작성자는 `—`로 표시합니다.
- 이미지 접기는 화면 표시 제어이며 다운로드 차단이 아닙니다. 개별 펼침 상태는 현재 대화에서만 유지하며 대화 이동·재접속 시 모두 접힌 상태로 초기화됩니다. 스포일러는 펼친 뒤에도 원래 공개 동작이 필요합니다.
